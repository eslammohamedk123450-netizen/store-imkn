# ADR-0001: حزمة تقنية مقترحة

- الحالة: PROPOSED؛ تحتاج موافقة.
- السياق: سوق مصر، عربي/إنجليزي، SEO، تفضيل Supabase وبدء على Vercel/مجاني.
- المقترح: Next.js App Router + TypeScript على Vercel؛ Supabase Postgres/Auth/Storage؛ GitHub CI/Pages للوثائق فقط.
- السبب: دعم SSR وتجربة ويب حديثة وخدمات بيانات/Auth المطلوبة، نشر معاينات وبدء اقتصادي محتمل.
- المخاطر: حدود الخطط المجانية تتغير؛ RLS تحتاج خبرة؛ lock-in؛ الوظائف الطويلة غير مناسبة لمسارات قصيرة.
- بدائل: SPA ثابتة + API منفصل؛ استضافة ذاتية/Postgres؛ اختيارها يتطلب قرار تشغيل.
- اختبار القرار: نموذج أولي لاحق يقيس SSR/SEO وRLS والنشر والنسخ والاستعادة والتكلفة ضمن usage المتوقع.

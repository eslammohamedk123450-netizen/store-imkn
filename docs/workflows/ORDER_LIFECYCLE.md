# دورة حياة الطلب

مسودة حالات: `pending_payment` (إن لزم) → `confirmed` → `processing` → `shipped` → `delivered`؛ بدائل `cancelled`, `return_requested`, `returned`, `refund_pending`, `refunded`. لا يغير العميل حالة الدفع أو الطلب مباشرة. انتقالات مفوضة حسب الدور ونافذة العمل، مع ممثل وسبب ووقت وتدقيق. إنشاء الطلب يثبت snapshot السعر ويضمن توافر المخزون ذريًا؛ حالات الدفع والشحن مستقلة بقدر الحاجة. تطلب مراجعة تجارية للانتقالات قبل التنفيذ.

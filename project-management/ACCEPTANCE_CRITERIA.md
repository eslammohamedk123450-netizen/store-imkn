# معايير قبول عامة

1. المتطلبات المتأثرة مرتبطة بمعرف REQ/NFR ولا تغيير صامت.
2. تحقق server-side لكل عملية حساسة واختبار رفض للوصول غير المخول.
3. واجهة عربية/إنجليزية وRTL/LTR وmobile responsive حيث ينطبق.
4. حالات loading/empty/error/success وإمكانية استخدام لوحة المفاتيح.
5. اختبارات وحدة/تكامل/E2E مناسبة، نتائجها فعلية محفوظة.
6. لا أسرار أو PII في Git أو السجلات/fixtures؛ dependencies مفحوصة.
7. التغييرات قابلة للمراجعة، migration موثقة، ومراجعة rollback.
8. تحديث task/status/changelog/session مع دليل قبول ومشاكل متبقية.
9. لا `COMPLETED` مع test فاشل أو ملاحظة حرجة مفتوحة.
